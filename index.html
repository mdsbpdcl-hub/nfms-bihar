Read the reliability ranks with care. NFMS shows data as furnished by each utility. Several large utilities report near-zero interruptions, while Bihar's smart-metered feeders log outages automatically, so a low reliability rank partly reflects fuller reporting, not only more frequent supply failure.

About the data
  • Source: the public NFMS dashboard, nfms.powermin.gov.in. A scheduled job opens it every night, selects each State/UT and DISCOM in turn, and saves the figures the dashboard shows. Each utility's figures are for its own last refreshed day, shown in the tooltips.
  • Hours of supply is the average daily supply per feeder. "Excl. agriculture" leaves out agricultural feeders, which run on rostered supply.
  • SAIDI is the average interruption duration per consumer (hours) and SAIFI the average number of interruptions per consumer, from the NFMS reliability tile for the latest day. The national tile is not comparable with state values, so the median state is used for comparison.
  • DISCOMs lists each separately reporting utility, plus states that report as one utility.
  • Major cities come from NFMS's monthly cumulative reports (Downloads page).
  • Download the data: latest.csv · history.csv · cities.json
Data: National Feeder Monitoring System (Ministry of Power / RECPDCL), shown as received from utilities. This page is an independent view of that public data.
